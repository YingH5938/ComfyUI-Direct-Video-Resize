# Changelog

## 0.1.0

- First public release of `DirectVideoResize` and the file-path companion node.
- CUDA Lanczos for file and in-memory inputs, NVENC P5 encoding, and an optional CPU route.
- One-frame processing buffers for `Create Video` input and audio passthrough for compatible files.
- English and Chinese quick starts, an example workflow, and a reproducible RTX 5090 benchmark.
